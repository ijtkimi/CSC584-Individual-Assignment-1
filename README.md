# CSC584-Individual-Assignment-1(Personal Profile Application)

## Project Description

This project is a simple Personal Profile Web Application
developed using HTML, Java Servlet, JSP and CSS.

The application allows students to enter their personal
information through an HTML form. The submitted information
is processed by a Java Servlet using HTTP POST and displayed
on a JSP page.

## Technologies Used

- HTML
- CSS
- Java
- Java Servlet
- JavaServer Pages (JSP)
- NetBeans IDE
- GlassFish Server 4.1.1

## Application Features

1. Personal Profile Form
2. Student Information Input
3. HTTP POST Form Submission
4. Java Servlet Processing
5. JSP Profile Display
6. Responsive CSS Design
7. Background Image Styling

## Information Collected

- Full Name
- Student ID
- Programme
- Email
- Hobbies
- Self-Introduction


## How to Run the Application

1. Install JDK 8 and NetBeans 8.2.
2. Download or clone this repository.
3. Select File > Open Project.
4. Select the PersonalProfileApp project folder.
5. Right-click the project and select Clean and Build.
6. Right-click the project and select Run.
7. Open the application in your browser.
8. Fill in the personal profile form.
9. Click Submit Profile to view the submitted information.
